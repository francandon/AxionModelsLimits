Axion Models Limits

Interactive explorer for axion–photon coupling limits, experiment compilations and theoretical model bands. Fast, modern and browser-friendly.

About

The project collects experimental limits and theoretical models for axion-like particles and provides an interactive plotting tool to explore the parameter space (mass vs coupling). The explorer preserves the original visual style while optimising interactivity for web deployment.

Purpose

Make axion limits accessible and exploratory for researchers and the public: combine data, visualise constraints, and compare theoretical models in a single modern web app. The site runs the plotting app via Pyodide for full Python interactivity inside the browser.

Models & conventions

Below is a brief summary of the model parametrisation and notation used throughout the explorer. A full table of model-specific couplings is maintained in the repository and referenced in the literature.

Symbols

  • \(g_{a\gamma\gamma}\) — axion–photon coupling
  • \(g_{a\bar f f}\) — axion–fermion coupling (for fermion \(f\))
  • \(N_{\rm DW}\) — domain-wall number
  • \(C_{a\gamma\gamma},\; C_{a\bar p p},\; C_{a\bar n n},\; C_{a\bar e e}\) — dimensionless model-dependent coefficients

Parametrisation (EFT)

The effective Lagrangian used is:

\[ \mathcal{L} \supset \tfrac{1}{4} g_{a\gamma\gamma} F \tilde{F} - i g_{a\bar f f} \bar f \gamma_5 f - \tfrac{i}{2} g_d a \bar n \sigma_{\mu\nu} \gamma_5 n F^{\mu\nu} \] \[ g_{a\gamma\gamma} = \frac{\alpha}{2\pi} \frac{C_{a\gamma\gamma}}{f_a}, \quad g_{a\bar f f} = C_{a\bar f f} \frac{m_f}{f_a}, \quad g_d = \frac{C_{anf}}{m_n f_a} \]

How it works (high level)

  1. Data & plotting functions live in PlotFuncs.py and the limit_data/ folder.
  2. The browser downloads a small assets bundle and runs the Panel app via Pyodide.
  3. Interactive widgets are optimised to minimise file I/O and expensive figure recreation.
  4. Explorer preserves existing features: model bands, experimental limits, download button and configurable axes.
